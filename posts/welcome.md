This is the first post on this site. It's a placeholder to show how things work.

To add a new essay:

1. Create a new file in the `posts/` folder, named something like `my-essay-title.md`.
2. Add a "front matter" block at the top (the part between `---` lines) with a `layout`, `title`, `date`, and optional `summary`.
3. Write your essay below it in Markdown.
4. Commit and push — the site rebuilds and publishes automatically.

That's it. Delete this post whenever you're ready.
